# 采集字段定义（引导 + 字符上下限 + 校验）

> 第 0 / 1 步必读。严格按本文件的**顺序**提问，按**字符下限–上限**校验。
> 字符数按中文字符计（1 个汉字 = 1 字符，标点也算）。★ = 必填。

## 提问与校验通则
- 一次只推进**一个板块**；板块内字段可一并列出，但逐个校验。
- 每个字段展示：字段名 · 是否必填 · **下限–上限字符** · 一句话提示 · 一个示例。
- 用户作答后校验字符数：
  - 低于下限 → 告知"还差约 N 字"，并给 1 条具体扩写方向（对应某项能力）。
  - 高于上限 → 告知"超出约 N 字"，给 1 条精简建议。
  - 合规 → 进入下一字段。
- 可重复板块（④⑤）每完成一段就问"还有下一段吗？"。
- 用户说"跳过 / 没有" → 非必填字段留空跳过；必填字段说明为何需要、鼓励至少给一句。
